# Breach Monitor Bot

بوت تيليجرام: تبعتله إيميل، بيرجعلك تقرير إذا هالإيميل ظهر بأي تسريب بيانات معروف —
مع خيار اشتراك مدفوع للمراقبة المستمرة وتنبيه فوري عند تسريب جديد.

## كيف بيشتغل

### الفحص المجاني (فوري، بدون اشتراك)

1. المستخدم يبعت `/start` فيطلع له شرح مختصر.
2. يبعت إيميله كنص عادي.
3. البوت يتحقق من شكل الإيميل، وبعدين يسأل [XposedOrNot](https://xposedornot.com) —
   خدمة عامة ومجانية لفحص التسريبات — إذا هالإيميل ظهر بأي تسريب معروف.
4. يرجّع تقرير بالعربي: أسماء التسريبات إذا في، ونصايح أمان عملية.

الإيميل بيتبعت لحظياً للفحص وما بينخزن بهاد المسار — هاد مهم للخصوصية (GDPR).
فيه حد أقصى 15 ثانية بين فحصين لنفس المحادثة، حتى ما حدا يقدر يضرب الـ API المجاني
بطلبات متلاحقة.

### الاشتراك المدفوع (مراقبة مستمرة)

- `/subscribe` — يعرض خطتين وبيدفع المستخدم عبر **Telegram Stars** (نظام دفع مدمج
  بتيليجرام، ما بيحتاج حساب تاجر خارجي حتى نجربه):
  - **فردي** — 100⭐/شهر، مراقبة إيميل واحد.
  - **شركات** — 500⭐/شهر، مراقبة لحد 10 إيميلات (بديل عملي عن "فحص نطاق كامل"،
    لأنه فحص الدومين بذاته بـ XposedOrNot بيحتاج مفتاح مدفوع وتوثيق ملكية الدومين
    مسبقاً — غير عملي كخطوة أولى. المستخدم هون بس بيعطينا إيميلات فريقه واحد واحد).
- بعد الدفع، المستخدم يضيف الإيميلات يلي بدو مراقبتها بالأمر `/watch email@example.com`
  (وممكن يشيل وحدة بـ `/unwatch email@example.com`).
- `/mystatus` — يعرض حالة الاشتراك، تاريخ الانتهاء، والإيميلات المراقبة.
- كل يوم الساعة 9 صباحاً (UTC)، البوت يعيد فحص كل الإيميلات المراقبة، ويقارن
  النتيجة بآخر فحص محفوظ، وإذا في تسريب جديد يرسل تنبيه فوري بالمحادثة.
- الاشتراك ما بيتجدد تلقائياً (Telegram Stars بهاي المكتبة ما بتدعم خصم دوري
  تلقائي) — لما ينتهي، البوت يبعت تنبيه وحدة ويوقف المراقبة لحد ما يجدد بـ `/subscribe`.

بيانات الاشتراكات والإيميلات المراقبة (وآخر تسريب معروف لكل وحدة، للمقارنة) متخزنة
محلياً بملف `subscriptions.db` (SQLite) — ما بيترفع لـ git.

### حذف البيانات (GDPR)

`/deletemydata` — يمسح الاشتراك وكل الإيميلات المراقبة نهائياً من قاعدة البيانات،
بعد تأكيد بضغطة زر واحدة. مهم لأي مستخدم بده يمارس حقه بـ "الحذف الكامل" لبياناته.

## التشغيل محلياً

1. اعمل بوت جديد عن طريق [@BotFather](https://t.me/BotFather) على تيليجرام واخد الـ token.
2. ثبّت المتطلبات:

   ```bash
   pip install -r requirements.txt
   ```

3. انسخ `.env.example` إلى `.env` وحط فيه الـ token:

   ```bash
   cp .env.example .env
   ```

4. شغّل البوت:

   ```bash
   python bot.py
   ```

5. افتح البوت على تيليجرام وابعتله `/start`.

⚠️ الملف `subscriptions.db` بينبني تلقائياً بأول تشغيل بنفس المجلد.

## البنية

- `bot.py` — منطق البوت والردود (طبقة تيليجرام: أوامر، دفع، الفحص المجاني، الجدولة اليومية).
- `breach_check.py` — منطق الفحص، منفصل عن تيليجرام حتى نقدر نبدّل المزوّد
  لاحقاً (مثلاً HaveIBeenPwned المدفوع) بدون ما نلمس كود البوت.
- `db.py` — تخزين SQLite للاشتراكات والإيميلات المراقبة.
- `payments.py` — تعريف الخطط والأسعار (Telegram Stars) — عدّل الأرقام هون بس.

## الخطوات الجاية

- **المرحلة ٣**: فحص روابط فيشينغ، نسخة واتساب، تقرير شهري، لوحة تحكم للمشتركين.
- **اختبار حقيقي**: الأسعار والخطط بـ `payments.py` أرقام مبدئية — لازم نجربها مع
  مستخدمين حقيقيين قبل ما نعتمدها نهائياً.
- **الاستضافة**: البوت هلق بيشتغل بس لما جهازك مفتوح. حتى يشتغل ٢٤/٧ للمستخدمين
  الحقيقيين، لازم ينرفع على سيرفر (Railway/Render/VPS) بدل ما يضل شغال محلياً.
- **تشفير قاعدة البيانات**: `subscriptions.db` حالياً نص عادي غير مشفّر — كافي
  للتجربة، بس قبل أي إطلاق فعلي لازم نأمّن القرص/الصلاحيات على أي سيرفر يستضيفه.

## ملاحظة أخلاقية/قانونية

البوت بيستخدم خدمة عامة موثوقة (XposedOrNot) بدل التعامل المباشر مع أي بيانات مسروقة.
الفحص المجاني ما بينخزن الإيميل. المراقبة المستمرة (بعد اشتراك) بتخزن الإيميل والتسريبات
المعروفة له بقاعدة بيانات محلية — هاد لازم يترافق بسياسة خصوصية واضحة للمستخدمين قبل أي
إطلاق فعلي، بما إنه المشروع موجّه جزئياً من ألمانيا (GDPR).
