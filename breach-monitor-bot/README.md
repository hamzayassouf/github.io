# Breach Monitor Bot — MVP (Phase 1)

بوت تيليجرام بسيط: تبعتله إيميل، بيرجعلك تقرير إذا هالإيميل ظهر بأي تسريب بيانات معروف.
هاي المرحلة الأولى من فكرة "بوت مراقبة تسريب البيانات" — فحص لمرة وحدة، مجاني بالكامل،
بدون تخزين أي بيانات. الهدف: نتأكد إنه فيه ناس فعلاً بتستخدمه قبل ما نبني المراقبة المستمرة
والاشتراكات المدفوعة (المرحلة ٢ و٣).

## كيف بيشتغل

1. المستخدم يبعت `/start` فيطلع له شرح مختصر.
2. يبعت إيميله كنص عادي.
3. البوت يتحقق من شكل الإيميل، وبعدين يسأل [XposedOrNot](https://xposedornot.com) —
   خدمة عامة ومجانية لفحص التسريبات — إذا هالإيميل ظهر بأي تسريب معروف.
4. يرجّع تقرير بالعربي: أسماء التسريبات إذا في، ونصايح أمان عملية.

الإيميل بيتبعت لحظياً للفحص وما بينخزن محلياً بأي قاعدة بيانات — هاد مهم للخصوصية (GDPR).

## التشغيل محلياً

1. اعمل بوت جديد عن طريق [@BotFather](https://t.me/BotFather) على تيليجرام واخد الـ token.
2. ثبّت المتطلبات:

   ```bash
   pip install -r requirements.txt
   ```

3. انسخ `.env.example` إلى `.env` وحط فيه الـ token:

   ```bash
   cp .env.example .env
   ```

4. شغّل البوت:

   ```bash
   python bot.py
   ```

5. افتح البوت على تيليجرام وابعتله `/start`.

## البنية

- `bot.py` — منطق البوت والردود (طبقة تيليجرام فقط).
- `breach_check.py` — منطق الفحص، منفصل عن تيليجرام حتى نقدر نبدّل المزوّد
  لاحقاً (مثلاً HaveIBeenPwned المدفوع بالمرحلة ٢) بدون ما نلمس كود البوت.

## الخطوات الجاية (حسب خطة البناء)

- **المرحلة ٢**: اشتراك مدفوع — مراقبة مستمرة (تشيك دوري + تنبيه فوري)، فحص نطاق كامل
  للشركات، ربط بوابة دفع.
- **المرحلة ٣**: فحص روابط فيشينغ، نسخة واتساب، تقرير شهري، لوحة تحكم للمشتركين.

## ملاحظة أخلاقية/قانونية

البوت بيستخدم خدمة عامة موثوقة (XposedOrNot) بدل التعامل المباشر مع أي بيانات مسروقة،
وما بيخزن ولا بيشارك إيميلات المستخدمين. أي توسعة مستقبلية (تخزين للمراقبة المستمرة)
لازم تلتزم بـ GDPR بما إنه المشروع موجّه جزئياً من ألمانيا.
